로그 다운로더 사용 방법

1. 받은 ZIP 파일을 우클릭하고 "모두 압축 풀기"를 누릅니다.
2. 압축을 푼 폴더의 LogDownloader.bat를 더블클릭합니다.
3. PC와 콤마 기기를 같은 네트워크에 연결합니다.
4. 열린 화면에서 "기기 찾기" 또는 기기 IP 입력 후 "불러오기"를 누릅니다.
5. "저장 폴더…"로 위치를 지정하고 원하는 녹화의 "전체 받기"를 누릅니다.

Python을 따로 설치할 필요가 없습니다. runtime 폴더는 함께 두세요.
브라우저가 열리지 않으면 http://127.0.0.1:8778/ 에 접속하세요.
검은 실행 창을 닫으면 프로그램이 종료됩니다.
기본 저장 위치는 이 폴더 안 downloads입니다.
docs/User-Guide.pptx에 화면이 포함된 자세한 설명서가 있습니다.

지원: Windows 10/11 x64, Carrot Web의 dashcam API를 제공하는 기기.
일반 openpilot의 모든 버전을 지원하는 것은 아닙니다.
이 프로그램은 개인 제작 도구이며 comma.ai 공식 제품이 아닙니다.
